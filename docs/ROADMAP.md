# Forge Roadmap

This roadmap records product direction at a deliberately high level. It is not a closed implementation specification, acceptance checklist, or authorization to begin work.

## Phase 1 — COMPLETE

**Scope:** shell, responsive behavior, and Forge visual identity.

Phase 1 established the engineering-workstation frame, three-panel desktop hierarchy, responsive mobile tabs, PCB / FR-4 surface language, ENIG gold accents, mobile density, and status/safe-area refinements.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #1.

## Phase 2 — COMPLETE

**Scope:** Build Flow + Part Selection UX.

Phase 2 delivered guided slot states, dynamic required-CORE progress, `PartCard` 2.0, visible compatible/selected/blocked states and reasons, mobile orientation refinements, and a final closeout covering empty states, interaction semantics, contrast, and inherited CSS.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #4 and the Phase 2 closeout in PR #5.

## Phase 3 — COMPLETE

**Scope:** Forge Intelligence / Score / Insight / Guidance.

Phase 3 delivered a deterministic Forge Score for build integrity, with a CORE / Compatibility / POST / Power breakdown; prioritized Forge Insights; actionable category guidance; a PSU recommendation action; and mobile integration inside `Consumo y POST`.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #6.

## Future directions

Possible longer-term directions that are not yet implemented include:

- smarter product recommendations;
- Compare;
- visual PC preview;
- Build Complete experience;
- saved builds;
- shareable build presentation;
- Museum expansion.

The order, names, and scope of future work are not officially defined. Do not implement any future feature, phase, or supporting refactor without an explicit task from the user.
