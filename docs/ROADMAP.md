# Forge Roadmap

This roadmap records product direction at a deliberately high level. It is not a closed implementation specification, acceptance checklist, or authorization to begin work.

## Phase 1 — COMPLETE

**Scope:** shell, responsive behavior, and Forge visual identity.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #1.

## Phase 2 — COMPLETE

**Scope:** Build Flow + Part Selection UX.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #4 and the Phase 2 closeout in PR #5.

## Phase 3 — COMPLETE

**Scope:** Forge Intelligence / Score / Insight / Guidance.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #6.

## Phase 4 — COMPLETE

**Scope:** Visual Build / Digital Twin Foundation.

Phase 4 delivered the normalized `VisualBuildModel`, lightweight SVG schematic, live assembly states, compact preview, and expanded inspector across desktop and mobile.

Status: **COMPLETE / APPROVED / MERGED / PRODUCTION** through PR #8.

## Phase 5 — 3D WORKBENCH FOUNDATION (FUTURE)

**Objective:** use `VisualBuildModel` as the boundary for a real 3D renderer, camera, scene, components, and build states while retaining the Phase 4 SVG fallback.

## Phase 6 — CINEMATIC CONFIGURATOR EXPERIENCE (FUTURE)

**Objective:** evolve the overall composition toward the [Visual North Star](./VISUAL_NORTH_STAR.md): a central PC stage, left category rail, bottom component deck, compact tool rail, and premium product presentation, while retaining access to Forge's technical capabilities.

## Phase 7 — BUILD COMPLETE / PRESENTATION (FUTURE)

**Objective:** create the final assembly experience, bringing completion, Forge Score, POST, power, presentation, and sharing together.

Other possible longer-term directions include smarter product recommendations, Compare, saved builds, and Museum expansion. No future phase or feature begins without an explicit task.
